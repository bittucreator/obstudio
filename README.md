# OB Studio

Premium design partner for startups. Visit [obstudio.co](https://obstudio.co)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Admin Dashboard

Navigate to [http://localhost:3000/admin](http://localhost:3000/admin) to manage portfolio items.

## Features

- ✨ Modern, minimal design (black & white)
- 📱 Fully responsive
- 🖼️ Portfolio grid with category filters (Website, Product, Branding)
- 📤 Admin dashboard for uploading new work
- ⚡ Built with Next.js 14 + Tailwind CSS

## Pricing

- Up to 5 pages: $3,000
- Up to 10 pages: $5,000

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Geist Font Family
